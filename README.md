## 기술 스택
- Spring Boot 3.4.5
- Spring Security
- JPA/Hibernate
- Redis (Amazon Elasticache Valkey)
- MySQL 8.0.40 (Amazon RDS)
- AWS S3
- AWS EC2
- Firebase FCM


- Python 3.11 (with AWS Lambda)
- AWS Lambda & Amazon API Gateway (use for Lost and Notice Query)
